NOVA STORE — PRÊT À HÉBERGER
=============================

Ce dossier contient la version corrigée et sécurisée, prête à être envoyée
sur votre hébergement (ex. InfinityFree).

FICHIERS À UPLOADER (tous, dans le même dossier "htdocs/" ou "public_html/") :
- index.html
- style.css
- script.js       (version connectée au serveur PHP — remplace l'ancienne)
- app.php
- admin.html      (panel admin pour voir/valider les commandes)
- manifest.json   (fait fonctionner le site comme une application mobile)
- sw.js           (service worker : mode hors-ligne + installation)
- icons/          (icônes de l'application, dossier complet)
- .env            (contient votre numéro Orange Money ET votre mot de passe admin — ne le partagez à personne)
- .htaccess       (protège .env et vos commandes contre l'accès public)

AVANT D'UPLOADER :
1. Ouvrez le fichier .env et remplacez ORANGE_NUMBER par votre numéro
   Orange Money réel (ex. ORANGE_NUMBER=+2250700000000).
   Remplacez aussi ORANGE_LINK par votre lien de paiement Orange Money
   si vous en avez un (le bouton "Payer via Orange Money" s'affichera
   automatiquement au client). Si vous laissez la valeur par défaut,
   seul le numéro sera affiché au client.
2. Dans le même fichier .env, remplacez ADMIN_PASSWORD=CHANGE_MOI_MOT_DE_PASSE_ADMIN
   par un mot de passe fort et personnel (ex. ADMIN_PASSWORD=UnMotDePasseLongEtUnique2024!).
   C'est ce mot de passe qui protège l'accès à vos commandes clients.

PANEL ADMIN (voir et valider les commandes) :
- Une fois le site en ligne, ouvrez : https://votre-lien/admin.html
- Connectez-vous avec le mot de passe défini dans ADMIN_PASSWORD.
- Vous verrez la liste de toutes les commandes, avec leur statut :
    • "En attente"   → le client n'a pas encore signalé de paiement
    • "À vérifier"   → le client dit avoir payé, VOUS devez vérifier dans Orange Money
    • "Payée"        → vous avez confirmé la réception du paiement
    • "Rejetée"      → commande refusée (paiement non reçu, litige, etc.)
- Vérifiez toujours vous-même dans votre appli Orange Money que l'argent
  est bien arrivé AVANT de cliquer sur "Accepter / Marquer payée".
- Personne d'autre ne peut voir cette page sans connaître votre mot de passe :
  ne le partagez à personne et ne l'écrivez pas ailleurs sur le site.
- Vous pouvez aussi y créer des codes promo (section "🎟️ Codes promo").

APPLICATION MOBILE (Android / iPhone) :
- Le site fonctionne aussi comme une application installable, sans
  passer par le Play Store ou l'App Store (PWA).
- Sur Android/Chrome : un bouton 📲 apparaît en haut du site pour
  installer l'application directement sur l'écran d'accueil.
- Sur iPhone/Safari : ouvrez le site, appuyez sur le bouton
  "Partager" puis "Sur l'écran d'accueil".
- Une fois installée, l'application s'ouvre en plein écran, avec
  sa propre icône, et fonctionne même avec une connexion instable.

CE QUI A ÉTÉ CORRIGÉ :
- Un bug dans app.php empêchait l'enregistrement des commandes
  (erreur de syntaxe PHP) — corrigé.
- Ajout du .htaccess pour empêcher que n'importe qui puisse consulter
  votre fichier .env ou la liste de vos commandes (orders.json) en tapant
  leur adresse dans un navigateur.

APRÈS L'UPLOAD :
- Testez en ouvrant : https://votre-lien/health
  Vous devriez voir : {"success":true,"service":"NOVA STORE"}
- Si vous voyez une erreur 500, vérifiez que le dossier a bien les droits
  d'écriture (pour créer orders.json automatiquement).
- Testez ensuite que https://votre-lien/.env affiche bien une erreur
  d'accès refusé (403), et non le contenu du fichier.
- Testez enfin l'accès admin sur https://votre-lien/admin.html avec votre
  mot de passe.
